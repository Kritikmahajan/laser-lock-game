Overview

Simple UI Icons is a free set of 51 game UI icons, each drawn in three matching styles: Filled, Line and Border. That is 153 sprites, 512 × 512 PNGs with white art, so you tint them to any colour with the Image colour and no extra textures.

51 icons

Home, back, menu, settings, shop, coins, gems, gifts, sound, play and pause, locks and more: the buttons every game needs.

3 matching styles

Filled, Line and Border versions of every icon, so one game can mix them.

Any colour

White art: the Image colour becomes the icon colour. Border outlines stay black.

Ready to drop in

Already imported as sprites. Drag one onto an Image and you are done.

Quick start

  1. Import the package Everything lands in Assets/HardArtcore/UI/SimpleIcons.
  2. Browse the icons Open Scenes/DemoScene: three scroll views show every icon in each style.
  3. Use one Add a UI › Image to your Canvas and drag a sprite from Sprites/Icons/<Style> into its Source Image. Tick Preserve Aspect.
  4. Tint it Set the Image's Color. White keeps the art as it is.

The three styles

Filled
Solid white shapes with cut-out details. Bold and readable at small sizes. Files: Filled/ic_<name>_fill.png.
Line
Rounded white outlines for clean, minimal menus and HUDs. Files: Line/ic_<name>_lines.png.
Border
A white shape with a thick black outline and a baked drop shadow, for a cartoon look. Files: Border/ic_<name>.png.

Tinting

The art is white, and Unity multiplies a sprite by its colour, so the colour you set is the colour you see. In the Border style the black outline and shadow stay black, since black times any colour is black.

The same works with a SpriteRenderer (spriteRenderer.color) and in UI Toolkit, with the sprite as background-image and -unity-background-image-tint-color for the colour.

Import settings

The PNGs are imported as Sprite (2D and UI), Single, with Alpha Is Transparency on. They are 512 × 512, so they stay sharp on large buttons. For small icons on mobile, lower Max Size (128 or 256) in the import settings or pack them into a Sprite Atlas to save memory.
